# Case design

## Blueprint

```text
Summary: 1–2 paragraphs
Problem: legal question, type, priority source
Facts: no. · description · date · known / alleged · relevance
Missing facts: what to ask the lawyer
Parties: role (plaintiff, defendant, public body, court, third party)
Norms: reference with locator · rank · status in Diké · confidence
Relevant acts: contracts, resolutions, judgments, official letters
Case hypotheses: H1–H3 · thesis · initial strength · what would defeat it
Route: action or appeal · court or authority · deadline milestones (confirmed by the procurador)
Proposed structure: introduction · grounds (facts, law, case law) · prayer for relief · evidence
Risks: adversarial, procedural, evidentiary
Missing information
```

## Rules

1. The relevant constitutional norms first, then the applicable statute.
2. Check hierarchy, competence, temporal validity and subject-matter scope before applying speciality, and write down any conflict (see `context/jerarquia-de-fuentes.md`).
3. The blueprint must have at least claims, key facts, applicable norms, available evidence and risks. If any is missing, it is not ready for drafting.
4. When new information arrives, update the same blueprint instead of starting another.
5. If there is no viable route, say so.
